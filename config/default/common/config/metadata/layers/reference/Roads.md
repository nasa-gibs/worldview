The Roads layer is a reference layer that displays the road network including interstates, highways, and roads.

Roads information are provided by Esri, TomTom, Garmin, FAO, NOAA, USGS, © OpenStreetMap contributors, and the GIS User Community via the [Hybrid Reference Layer (WGS84)](https://www.arcgis.com/home/item.html?id=a70340a048224752915ddbed9d2101a7).

Alignment of roads is a presentation of the feature provided by our data vendors and does not imply endorsement by Esri or any governing authority.
